# 案例：回到臺灣

[回課程首頁](../../README.md) · [板塊交界帶總表](../../plate-boundaries.md)

取代 [`2026_utaipei_plate_tectonic`](https://github.com/oceanicdayi/2026_utaipei_plate_tectonic) 教材網頁「八、回到臺灣」原本的手繪示意圖，改用真實資料重畫。

## 看到什麼

`taiwan_map.py` 產出 `taiwan_map.png`：範圍 117–124.5°E、19–26°N，疊上：

- 地形（GMT `earth_relief`，02 角分）
- USGS 地震（2000 年起 M≥4.5，依深度上色：紅 0–70 km／橘 70–300 km／藍 300–700 km）——北邊琉球海溝、南邊馬尼拉海溝兩道隱沒地震帶方向相反
- NCEI/GVP 全新世火山（白色三角）
- 中央山脈、西部麓山帶、花東縱谷的示意標示（依已知地理位置標出，非精確斷層線）
- 菲律賓海板塊相對歐亞板塊的聚合方向箭頭（約 N306°E，約 8 cm/yr，Yu et al. 1997）

## 屬於哪一類交界帶

臺灣不是單一類型：北邊菲律賓海板塊向北隱沒到歐亞板塊之下（琉球海溝），南邊歐亞板塊（南海）向東隱沒到菲律賓海板塊之下（馬尼拉海溝），中間是弧陸碰撞、花東縱谷為兩板塊縫合線。三種構造擠在同一個島上。

## 哪裡不確定

- 中央山脈、西部麓山帶、縱谷的標籤位置是依課本慣用的地理描述放置，不是精確測量的斷層／地質分區邊界。
- 地圖範圍內的地震深度分帶在平面圖上不如剖面圖清楚；要看到清楚的 Wadati-Benioff 傾斜帶，需要另外沿垂直海溝方向切剖面（可比照 `examples/02_region_map_section.py` 或 Sunda Strait 案例的做法）。

## 重跑

python3 taiwan_map.py
